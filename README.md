# TrulySafeGuard · 隐私守护

隐私守护是一款 Android 手机应用。你可以过滤广告请求、自动点击开屏广告的「跳过」、保留验证码并移除促销通知，也可以限制数字助理读取当前界面，查看谁正在通过标准接口共享屏幕。最低支持 Android 8（API 26），包名为 `app.local.privacyguard`。

**1.2.1 下载**　[Android 安装包](https://github.com/Ar1haraNaN7mI/trulysafeguard/releases/download/v1.2.1/TrulySafeGuard-1.2.1.apk) · [可选的电脑激活工具](https://github.com/Ar1haraNaN7mI/trulysafeguard/releases/download/v1.2.1/TrulySafeGuard-1.2.1-helper.zip) · [完整使用手册](docs/usage.zh-CN.md)

1.2.1 修复了华为侧边手势热区造成的跳过控件遮挡误判。热区只覆盖按钮边缘、控件中心仍可操作时，守护现在可以继续。这个问题在 CET-AL00 的原生测试广告中复现。普通控件点击与携程专用轻触共用这项遮挡检查。

## 开始使用

1. 安装 APK 后，打开「全应用广告请求拦截」，按系统提示允许本地 VPN。它会过滤当前 Android 用户下各应用经系统 DNS 发出的广告域名请求，包括解析结果中指向拦截域名的别名。只想跳过已显示的广告时，可单独进入「自动跳过已显示的开屏广告」，按提示开启系统无障碍服务。两项可分别开关。
2. 想保留验证码并过滤促销时，开启「广告通知过滤」，在「管理系统通知访问」中授权，再到「选择应用与过滤规则」为目标应用选择「仅过滤促销关键词」。横幅或声音可能在守护移除通知前出现。
3. 需要限制网页或文件管理器安装应用时，打开「安装来源与新增应用」→「按应用管理安装来源」，关闭目标应用的系统安装授权。打开「记录新装应用」可查看最近 40 条安装记录，来源信息取决于系统，后台巡检也可能漏掉短时安装后立即卸载的应用。系统商店和特权安装器有独立的安装权限。

## 按需开启的功能

| 功能 | 使用方式和覆盖范围 |
| --- | --- |
| 摇一摇广告 | 支持相应权限的华为设备，可在「华为设备方向权限」中打开系统权限页，按应用关闭「应用获取设备方向」。规则助手也能限制所选普通应用的运动传感器回调。这会影响体感游戏等正常功能，广告仍可能通过点击触发。 |
| 开屏跳过 | 应用启动或从后台切回后的前六秒内，在手机上查找屏幕角落符合规则的原生跳过控件。无障碍服务可读取窗口、点击控件和发送手势。对核验过的携程版本，只有实时倒计时、控件布局和无遮挡状态均符合规则时才轻触一次。自绘广告、网页内广告或没有可识别按钮的广告可能保留。 |
| 网页与广告域名 | 设为默认浏览器后，守护可以拦截交给它的广告链接和可识别的安装包直链，或在打开外部网页前询问。域名拦截占用系统 VPN 连接。应用自带加密 DNS、直连 IP、业务同域广告及已缓存素材均可能继续使用。 |
| 屏幕共享监测 | 配置诊断权限后，进入「全局屏幕数据防护」，开启「在手机上持续监测」并允许提醒通知。前台服务读取标准 MediaProjection 会话并提示来源。厂商私有抓屏和无障碍读屏可能没有标准会话。 |
| 数字助理与受管设备 | 「阻止数字助理读取屏幕」可以关闭标准数字助理接收截图和界面结构的两项设置，保留个人截图。要在全设备限制标准截图与录屏，守护必须已具备设备所有者（Device Owner）身份，这项策略也会限制个人按键截图。 |
| 私密文件预览 | 「守护窗口防截屏」保护守护自己的窗口，支持预览选定的图片和 UTF-8 文本。开启后，你自己也无法截取这些窗口。 |
| 定位摇杆 | 「打开定位摇杆网页」支持手动输入经纬度、使用真实位置作起点，以及在 0–300 km/h 内调速。要向其他应用提供模拟位置，先在开发者选项选择守护为模拟位置应用。可选择离开页面后保持最后位置，并通过通知或网页停止。 |

开屏跳过的思路受到 SKIP 项目启发。本项目独立编写无障碍服务和识别规则，没有复制 SKIP 的代码或规则订阅。部分广告域名来自附有 MIT 许可的数据集。[SKIP 项目](https://github.com/GuoXiCheng/SKIP) · [域名数据来源与许可](app/src/main/assets/ad-domain-notice.txt)

## 可选的 USB 配置

电脑需有 Python 3.8+ 和 Android SDK Platform-Tools。解压与 APK 同版本的激活工具，启用手机的 USB 调试，连接后在手机上允许这台电脑调试。以下命令在**激活工具解压目录**运行。

| 想启用的能力 | 操作 |
| --- | --- |
| 独立投屏提醒 | 运行 `python activate_phone.py --screen-monitor grant`，然后在手机上开启监测。此命令单独授予 Android 的 `DUMP` 诊断权限。守护只用它查询标准投屏会话。要撤回可运行 `python activate_phone.py --screen-monitor revoke`。 |
| 按应用执行系统规则 | 运行 `python activate_phone.py`。工具核对手机所装 APK 的 SHA-256，启动规则助手。打开「系统级按应用控制」，确认有近期回报后，选择应用并保存规则。 |

助手可以限制运动传感器、拦截整应用普通通知、在检测到所选应用投屏后停止该应用，或禁止它请求安装。拦截整应用通知也会影响验证码，停止投屏来源会中断该应用的其他任务。助手轮询前已经传出的画面无法撤回。

在「全局屏幕数据防护」→「阻止数字助理读取屏幕」，已激活的助手可一次写入两项系统设置。效果在助手退出后保留。恢复时重新连接助手，点「恢复助理的原有设置」。如需卸载，先恢复助理设置，再对其他按应用规则执行「暂停并恢复设置」并核对回报。

## 真机验证

在 CET-AL00（HarmonyOS 4.2，Android 12 接口）上使用正式发布的 1.2.1，菜鸟、淘宝、闲鱼、携程和小红书在后台停留 60–93 秒后均以原进程回到前台。采样时五款都没有可识别的广告控件，守护未记录自动跳过，携程的轻触次数也是 0。五段观察期间全机 DNS 拒绝总数增加 18，这一计数无法归因到某个应用或某次广告。菜鸟、淘宝、闲鱼的 APK 中已核实原生跳过控件资源名，但本轮没有验证到五款中任何一款实际跳过商业广告。

在同一台手机上使用正式发布的 1.2.1，系统 DNS 查询新增广告主机下的随机子域时，守护的拒绝计数增加，查询没有得到地址，正常域名 `example.org` 仍能解析。在此前的 1.2 测试中，从守护界面关闭数字助理的截图和界面结构请求后，两项系统设置均回读为 `0`，恢复后两项都回到原有的系统默认，再次关闭也成功。

1.2 在 CET-AL00 的原生测试广告中漏掉了跳过按钮。用正式发布的 1.2.1 在同一台手机上依次切回普通表单、原生合成广告、同一表单，测试应用的累计点击数为 **0 → 1 → 1**。广告的跳过控件收到一次点击，两次表单中的普通「跳过」均未触发。遮挡对照在模拟器中验证，覆盖按钮边缘时合成广告控件收到 1 次轻触，遮住中心时为 0 次。

模拟器另用独立测试包和签名验证两条专用规则。模拟携程布局且倒计时递减时，控件收到 1 次轻触。倒计时静止、倒计时逆序或文案改为「支付」时均为 0 次。模拟小红书广告页面的「跳过」被点击 1 次，普通表单页面的相同文案为 0 次。上述结果来自可计数的合成界面。

另在具备 Device Owner 的 Android API 37 模拟器中，对独立测试应用启用标准截图策略，系统截图和录屏解码的首帧均从测试色块变成黑色。关闭策略后两者都恢复原色。CET-AL00 按普通安装测试，未启用全设备策略。

此前 1.1 使用合成通知和无画面的测试投屏验证了以下行为。其他系统版本的权限和后台行为可能不同。

| 测试条件 | 实际结果 |
| --- | --- |
| 物理断开 USB，在手机上发送两条测试通知 | 促销通知被移除，验证码保留。文件传输模式下重新接线后，规则助手进程已退出。回报过期时，新的系统规则要重新激活助手才会同步。 |
| 保持 USB 连接，结束规则助手，只运行普通应用的监测服务 | 开始测试投屏后，守护识别出来源包并发出系统提醒。停止后，页面恢复为无标准会话。独立投屏监测的实测范围截至上述有线条件。 |
| 保持 USB 连接，启用规则助手 | 测试应用的加速度回调停用后可恢复，普通通知和安装来源授权限制也可恢复。助手按规则停止了已授权的测试投屏。 |
| 将编码后的 APK 直链交给守护 | 守护结束跳转，系统未观察到浏览器接手。另行安装的测试应用卸载后，守护仍保留新装记录，安装方显示为「系统未提供」。 |

## 从源码构建

准备 Python 3.8+、JDK 17+、Android SDK Platform 35 或更高版本及近期 Build Tools。配置 `JAVA_HOME` 和 `ANDROID_SDK_ROOT` 后，在仓库根目录运行下列命令。第二行通过已授权的 ADB 连接安装构建结果。

```sh
python build.py
adb install -r build/PrivacyGuard.apk
```

首次构建会在 `.signing/` 生成本地签名，后续覆盖更新需要相同签名。请私下备份该目录。使用自建 APK 时，以 `python activate_phone.py --apk build/PrivacyGuard.apk` 激活助手。同一条命令可追加 `--screen-monitor grant` 单独配置投屏监测。

安卓界面、前台服务和本地定位网页在 `app/src/main/`，固定系统规则在 `phone-helper/`。通知正文在内存中匹配，投屏监测只保存断线采样时间，不采集屏幕画面。放行的 DNS 查询仍由当前网络的解析服务处理。
