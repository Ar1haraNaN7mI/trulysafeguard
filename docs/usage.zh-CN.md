# 隐私守护 1.2 使用手册

手机包名为 `app.local.privacyguard`，最低支持 Android 8。CET-AL00 使用 HarmonyOS 4.2 的 Android 12 接口。安装后，你仍然可以自己截图。防护由你在手机上选择应用和开关。

## 拔线后如何使用

| 需要的保护 | 在手机上怎么开 | CET-AL00 的作用范围 |
| --- | --- | --- |
| 促销通知过滤 | 首页「广告通知过滤」选来源与关键词，按系统提示授权通知访问，再确认服务已连接 | 已在物理断开 USB 的情况下验证，合成促销提醒被移除，测试验证码保留。 |
| 限制摇一摇 | 首页「华为设备方向权限」→「打开华为权限管理」→「应用获取设备方向」，关闭目标应用 | 华为系统保存权限。以后直接在手机的同一系统页查看和修改。可能同时影响该应用的体感游戏和方向功能。 |
| 限制安装来源 | 首页「安装来源与新增应用」→「按应用管理安装来源」，在系统页关闭浏览器、文件管理器等应用的授权 | 系统保存设置并检查后续普通安装请求。「记录新装应用」可由手机本地巡检，提供安装后记录。 |
| 监测屏幕共享 | 首页「全局屏幕数据防护」→「在手机上持续监测」，并开启守护的提醒通知 | 普通应用前台服务只读查询系统提供的标准会话，保留你的按键截图。CET-AL00 已验证关闭规则执行器后仍可识别会话和提醒。本项测试期间 USB 保持连接，物理拔线后的效果尚未实测。 |

「系统级按应用控制」内的四项规则使用由 USB 调试授权启动的执行器。在这台 CET-AL00 的文件传输模式下，拔线测试后执行器已不在运行，面板失去回报。失联期间已写入的权限有可能继续有效，随后在面板修改的规则要等重新激活才能同步。文件传输模式可以照常保留。

## 连接电脑配置系统级规则

1. 在手机上安装配套的签名 APK。电脑需要 Python 3.8 或更新版本，以及 Android SDK Platform-Tools 中的 `adb`。可把 adb 加入 PATH，也可设置 `ANDROID_SDK_ROOT` 指向 Android SDK。Windows 默认的 Android SDK 安装位置也会被检查。[Android 官方 Platform-Tools](https://developer.android.com/tools/releases/platform-tools)
2. 在手机启用 USB 调试，插线、解锁并允许这台电脑调试。将 `TrulySafeGuard-1.2-helper.zip` 完整解压到同一个文件夹。Windows 双击「双击运行.cmd」。其他系统可在该目录运行 `python3 activate_phone.py`。电脑连接多台设备时，使用 `--serial 设备序列号` 指定手机。adb 安装在其他位置时，可用 `--adb 路径` 指定。
3. 工具会核对已安装 APK 的 SHA-256，启动 APK 内的规则执行器并等待回报。打开手机「系统级按应用控制」，核对最近回报时间和每项规则的执行状态。
4. 在面板选择要管理的应用，勾选并保存规则。执行器支持主用户安装的可启动、拥有独立 UID 的普通应用。即使面板仍保留开关选择，回报过期后新改动也只能待同步。需要恢复或继续执行时，保持文件传输模式连回已获授权的电脑，再运行匹配的激活包。

有近期回报时，「暂停并恢复设置」会尝试撤销助手的按应用规则，保留规则选择。「恢复规则运行」会再次执行已选规则。「结束手机助手」会尝试恢复按应用设置并退出。数字助理的两项设置有单独的恢复按钮。卸载前先恢复助理设置，再核对各应用的恢复回报。手机重启、彻底结束助手、系统终止它或更换 APK 后，需要再次用电脑运行匹配的激活包。

系统重启会清除传感器服务的临时覆盖。已写入的通知、安装来源限制可能继续生效。即使规则仍显示勾选，也请以近期回报为准。重新激活后可以用「暂停并恢复设置」核对并恢复。通过华为权限页面或 Android 系统设置手工选择的开关由系统保存。

## 系统级按应用控制

| 开关 | 在哪里生效 | 使用时应留意 |
| --- | --- | --- |
| 限制运动传感器 | 执行器在线时要求系统传感器服务限制目标应用接收运动数据 | 摇动触发、计步、方向感应或游戏体感可能一并受影响。广告画面、点击跳转和倒计时可能继续出现。系统的 active / idle 回报无法区分其他工具以前设置的同类覆盖。 |
| 拦截该应用的普通通知 | 助手检查所选应用的系统授权。CET-AL00 的系统已经提供 Android 通知运行时权限，助手可撤回并恢复可更改的授权。较早系统没有该权限记录时使用通知 AppOp | 消息和验证码也会受影响。来源应用可以查询通知状态，通话、媒体等系统豁免按设备规则处理。[Android 通知权限和豁免](https://developer.android.com/develop/ui/compose/notifications/notification-permission) |
| 检测屏幕共享后停止该应用 | 执行器在线时轮询标准 MediaProjection 会话，核对来源包和 UID，再请求系统停止命中的应用。执行器失联后停止监视 | 保留你自己的按键截图。初始画面可能已经传出，来源应用的其他任务也会中断。系统特权路径、无障碍读取及厂商私有抓屏超出这项检查范围。 |
| 禁止该来源请求安装 | 对声明了安装请求权限的所选普通应用，助手在系统 AppOps 层设置限制 | 适用于浏览器、文件管理器等通过 Android 普通安装授权流程发起的请求。文件仍可能下载。系统商店、特权安装器、设备管理策略和获准的调试安装有独立权限。 |

设备方向授权以华为系统页为准。[华为 HarmonyOS 4.2 摇一摇广告说明](https://consumer.huawei.com/cn/support/content/zh-cn16002151/)

## 过滤广告域名与跳过开屏

首页「全应用广告请求拦截」启动本地 DNS VPN。开启时，同一 Android 用户下使用系统 DNS 的各应用都会使用这套规则，无需逐个勾选。打开应用或从后台返回后，如果需要重新解析域名，就会重新检查。域名规则匹配主机及其子域名，也检查从当前查询出发的 CNAME 链和 SVCB/HTTPS 别名模式。缓存素材、直连 IP、自带加密 DNS，以及广告与业务共用一个域名时仍可能显示广告。本地 VPN 占用当前用户的 VPN 连接。[内置域名来源及许可](../app/src/main/assets/ad-domain-notice.txt)

要处理已经显示的开屏广告，点「自动跳过已显示的开屏广告」，打开「自动跳过开屏广告」，在系统无障碍设置中允许「隐私守护 · 开屏广告跳过」。此服务与 DNS 可分别开启和关闭。

Android 的无障碍授权允许读取窗口、操作控件和发送手势。守护在可启动的第三方应用打开或切回的前六秒内查找原生控件，核对窗口、资源名或文案及角落位置。密码输入框、可识别的敏感界面、系统应用及 WebView 不在处理范围。服务不截屏、不保存页面内容。

- 菜鸟、淘宝和闲鱼使用从相应 APK 核实的资源名，控件仍需在当前可见窗口中满足点击条件。小红书的两种已核实开屏广告 Activity 还支持依据当前页面可点击的原生「跳过」文案识别。
- 携程 8.98.1（版本号 2140）的一种跳过布局使用触摸监听。守护先核对软件包签名及版本，再检查实际前台窗口中「跳过广告」与相邻且正在递减的倒计时、控件位置及遮挡。所有检查通过后，才会对当时的控件中心发送一次轻触。
- 最近来源包、系统接受控件点击的次数和携程已完成触摸的次数仅在进程内存中保存。点击或手势送达表示系统已处理该操作，商业广告是否消失仍须在实际展示时验证。

## 标准投屏监测

这项监测由普通应用前台服务运行，打开后会显示常驻通知。要单独配置系统诊断权限，在电脑连接手机时从激活包目录运行 `python activate_phone.py --screen-monitor grant`。工具先校验配套 APK，只为监测配置诊断权限，无需启动规则执行器。要撤销可运行 `python activate_phone.py --screen-monitor revoke`。Android 的诊断权限覆盖多种系统状态，本应用的这一功能只请求 MediaProjection 的会话状态。

系统还要允许应用实际读取 MediaProjection 状态。CET-AL00 真机测试时，已结束调试规则执行器并确认该进程退出。仅靠普通应用的监测服务，手机先显示无标准会话，随后准确识别测试应用创建的活动会话并发布系统提醒。测试会话结束后，监测结果恢复为无标准会话。测试期间维持 USB 文件传输模式和物理连线，此项未进行第二次物理拔线验证。

若系统拒绝访问或返回无法解释的结果，页面会提示无法判断。用户可以在系统录屏通知中结束共享。

本应用没有注册投屏监测的开机自启。手机重启或手工强行停止应用后，请重新打开「全局屏幕数据防护」，按页面回报重新开启。在后台服务没有运行、监测结果过期或系统暂时读不到会话期间，页面和通知不能证明屏幕共享已停止。

在「系统级按应用控制」为某个应用勾选屏幕共享项后，还可在监测页面开启可选的前台服务提示。它需要已连接的通知访问服务，仅在相关应用声明录屏服务并发布前台服务通知时提供线索。前台服务通知本身不能证明正在录屏。独立监测不会自动终止其他应用，厂商特权取屏及无障碍读屏可能完全不产生标准会话。

## 阻止标准数字助理获取屏幕数据

1. 确认「系统级按应用控制」有近期助手回报，进入首页「全局屏幕数据防护」→「阻止数字助理读取屏幕」。
2. 点「禁止助理读取截图和界面结构」。助手保存原值，并将主用户的 `assist_screenshot_enabled` 和 `assist_structure_enabled` 设为 `0`。页面分别回读两项状态。Android 标准助理在获取截图和界面结构之前会检查这些设置。个人按键截图仍可用。
3. 两项值写入后由系统保存，拔线或结束助手后仍可起作用。需要撤销时，使助手重新在线，再点「恢复助理的原有设置」。该操作会恢复助手更改的值，也会保留用户后来自行更改的值。其他录屏接口、无障碍服务及厂商私有通道有各自的授权。

CET-AL00 的系统服务代码显示，标准数字助理通道会在请求截图或界面结构之前读取对应设置。在这台手机上，通过守护页面将原本均为系统默认的两项设为 `0`，恢复到系统默认，再次设为 `0`，每一步都核对了实际值。验证仅涉及设置和标准调用路径，未采集个人屏幕画面。

## 受管设备的屏幕数据策略

进入「全局屏幕数据防护」可以查看本应用的管理身份及系统回报。同一页提供以下两项独立开关。

| 开关 | 谁有权设置 | 对自己截图的影响 |
| --- | --- | --- |
| 限制系统截图与录屏 | 已部署为设备所有者（Device Owner）时，标准策略覆盖全设备。资料所有者仅可管理其受管用户或资料。普通安装时开关不可用。 | 策略限制范围内的手动截图和标准录屏都会受限。希望保留自己截图时，应保持此项关闭。 |
| 限制 Android 屏幕内容采集服务 | 需要 Android 10+、可用的 Content Capture 服务及对应管理身份。设备所有者针对主用户设置，资料所有者针对受管用户或资料设置。 | 此项只限制系统 Content Capture 框架向内容服务提供界面数据，手动截图仍可用。 |

在 Android API 37 模拟器中，测试管理员以设备所有者身份切换标准截图策略，由另一个包名、另一份签名的应用显示两块已知颜色。开启前，系统截图和录屏解码出的首帧都呈现原色。开启后，两处读数都变成黑色，关闭后都恢复原色。用于日常防护实测的 CET-AL00 没有授予守护设备所有者身份。

## 安装来源防护

- **下载前。** 「拦截安装包网页直链」检查由 Android 交给守护的 HTTP/HTTPS 链接，根据可识别的文件名和下载参数拦截。浏览器内部下载、动态生成的文件以及其他协议可能绕过。
- **请求安装时。** 「按应用管理安装来源」打开对应应用的系统授权页，可在手机上关闭「允许安装未知应用」。声明了该权限只表示应用有资格请求。具体授权以系统页面为准，授权变化由系统保存。已作为设备或资料所有者部署的本应用还可以设置本管理员的未知来源限制。[Android 安装来源 API](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls())
- **安装后。** 开启「记录新装应用」后，守护在手机保存最近 40 条新安装记录，包括包名、首次安装时间和系统提供的来源。打开页面可立即核对，也可清空本地记录。后台巡检受系统调度，短时安装后又卸载的应用可能漏记。系统可能不提供来源，记录也无法判定当时是否弹出过确认框。

## 其他独立功能

- **按内容过滤促销通知。** 在「广告通知过滤」选择来源及关键词，并通过系统页面授予通知访问即可独立运行。来源应用先正常发布，守护再按规则移除，有时会先闪现横幅或发声。按应用可选择促销关键词，或移除可清除的普通通知。关键词可能误判，持续任务及可辨认的关键通知会被保留。通知内容仅在内存中匹配。
- **网页和域名。** 系统将「隐私守护」设为默认浏览器后，它可以接收外部网页跳转。命中广告域名会静默拦截。其余可选择确认打开或全部拦截。应用内网页、已验证的 App Link 和显式唤起其他应用可能绕过。通过本地 VPN 的域名拦截可过滤系统 DNS，并与网页跳转共用自定义域名规则。Android 每个用户只有一个 VPN 位置。应用自行加密 DNS、直连 IP 或业务与广告共用域名时，覆盖会受限。
- **自己的敏感窗口。** 可选的「守护窗口防截屏」用于守护面板、应用内弹窗和私密文件预览，启用后也会限制你自己的截图。私密预览支持选定的图片和 UTF-8 文本。私密文本在画布上分页面绘制，因此屏幕朗读也会受到限制。只有本应用已经作为设备或资料所有者部署时，才显示对应的系统级截屏策略。
- **定位摇杆。** 需要真实起点时点「用当前位置作起点」，在系统设置打开定位并同意前台定位。可编辑经纬度，用摇杆设置方向和力度，速度范围为 0–300 km/h。网页本地预览可直接使用。在应用内使用「手机模拟」时，须先在开发者选项中选本应用为模拟位置信息应用。默认离开网页会结束模拟，勾选「切到其他应用时保持最后位置」后，可从通知栏或网页停止。其他应用可以识别 Android 模拟位置标记。普通浏览器打开附带的离线网页时可预览轨迹。[Android 模拟定位设置](https://developer.android.com/studio/debug/dev-options#debugging)

## 数据与构建

应用没有账号、广告或统计 SDK。手机保存你选择的包名、规则、必要的系统设置恢复记录，以及可选的安装记录。助手在手机上处理系统回报，不保存截图、录音、短信、聊天正文、通知正文或真实位置轨迹。私密文件只在预览时读取。放行的 DNS 查询仍由当前网络的解析服务处理。

源码包含 Android 应用、固定操作的手机助手、激活脚本及构建脚本。构建需要 Python 3.8+、JDK 17+、Android SDK Platform 35+ 及 Build Tools。配置 `JAVA_HOME` 与 `ANDROID_SDK_ROOT` 后在源码目录运行 `python build.py`，安装包生成于 `build/PrivacyGuard.apk`。首次构建会在本机 `.signing/` 生成独立签名。使用自建版本时，激活命令为 `python activate_phone.py --apk build/PrivacyGuard.apk`。Android 要求覆盖更新保持相同签名。

源码内保留 1.0 的电脑端 `usb_guard.py`，用于原有电脑规则收尾。若曾用 1.0 助手更改权限，先让它恢复原规则并退出，再启用 1.2 手机助手，以免两个执行器争用同一系统设置。
